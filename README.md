# homebrew-intel

Intel macOS (Sequoia) bottles built by [brew-bottle-farm](https://github.com/lurepheonix/brew-bottle-farm).

```sh
brew tap lurepheonix/intel
brew install lurepheonix/intel/<formula>
```

Bottles carry the `sequoia` tag (macOS 15 on Intel). Each formula version
has its own GitHub Release (`<formula>-<version>`) holding the bottle
tarball.
